Project Overview
Build a modern, production-ready full-stack web application using Laravl for an Investment Client Portfolio Management System.
The application should follow enterprise software development best practices with a clean architecture, responsive UI, secure authentication and scalable database design.

Client Portfolio Module
The Client Portfolio page will be in two version, one for admin and another one for staff, the staff version will show all client portfolio in a list and staff will only be able to view their portfolio details. But for admin,  admin will be able to create new portfolio and Edit  and Delete portfolio, details as described below:
•	Client Name(this will be at the top it will be a select button who’s data is populated from client name field in “Client information” module
Then portfolio details are divided into three part.
1. Fixed Debt Instrument: 
Make it like a table columns
Fields:
•	Description
•	Amount
•	Status
Actions:
•	View
•	Edit
•	Delete
•	Print
•	Export PDF

a. Payment Details:
For each fixed debt instrument there will be details of the portfolio as explained below:-
Fixed debt instrument details: Add ability to add, remove or edit any instrument details: 
It will go with header; the header will be a select button with data from “Description” field from Fixed debt instrument section.
Details fields:
•	Subscription Date
•	Instrument (Default data “CP”)
•	Tenor
•	Rental Rate
•	Settlement date

Subheading (Payment Breakdown)
Make it like a table columns
Field: 
•	ROI
•	Amount
•	Payment Date
•	Status (Options: Paid, Unpaid, Blank. Default is Blank (empty))
Status badges:
•	Paid
•	Pending
•	Not due
Actions:
•	View
•	Edit
•	Delete

2. Payment History: Add ability to add, remove or edit any equity details
Make it like a table columns
Fields:
•	Date
•	Amount Paid
•	Payment Status
Actions:
•	View
•	Edit
•	Delete

3. Equity: Add ability to add, remove or edit any equity details
Make it like a table columns.
Fields:
•	Stock
•	Unit
•	Price
•	Value (unit * price)
Actions:
•	View
•	Edit
•	Delete
